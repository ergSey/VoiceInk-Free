# VoiceInk-Free

**Бесплатные готовые сборки [VoiceInk](https://github.com/Beingpax/VoiceInk) для Mac на Apple Silicon.** Неофициальные, с автором не связаны. [English version](README.md)

**[⬇ Скачать последний DMG](https://github.com/ergSey/VoiceInk-Free/releases/latest)**

> [!IMPORTANT]
> Этот репозиторий не нужно собирать самому: скачайте готовый DMG из [Releases](https://github.com/ergSey/VoiceInk-Free/releases). Здесь лежит код оригинального VoiceInk и небольшой скрипт сборки. Чтобы собрать из исходников или следить за разработкой, идите в оригинальный проект: [Beingpax/VoiceInk](https://github.com/Beingpax/VoiceInk).

Автор VoiceInk продаёт готовое приложение за **$25** (разовая покупка на один Mac, см. [tryvoiceink.com/pricing](https://tryvoiceink.com/pricing), ноябрь 2026). Здесь то же приложение уже собрано и бесплатно. Если VoiceInk вам пригодился, **поддержите автора [покупкой лицензии](https://tryvoiceink.com/pricing)**: на эти деньги развивается приложение, которым вы пользуетесь.

VoiceInk может работать только на локальных моделях. Распознавание речи (whisper.cpp, Parakeet) и обработка текста ИИ (VoiceInk Refine на MLX или Ollama) идут на вашем Mac, поэтому диктовка очень быстрая и не требует интернета. Облачные провайдеры (OpenAI, Groq, Deepgram и другие) в приложении тоже есть, но для работы они не нужны.

## Установка

1. Скачайте `VoiceInk-<версия>-arm64.dmg` из [Releases](https://github.com/ergSey/VoiceInk-Free/releases).
2. Откройте DMG и перетащите VoiceInk в «Программы».
3. Приложение не нотаризовано Apple, поэтому macOS заблокирует первый запуск. Один раз выполните в Терминале:
   ```shell
   xattr -cr /Applications/VoiceInk.app
   ```
   или попробуйте открыть приложение, затем зайдите в «Системные настройки» → «Конфиденциальность и безопасность» и нажмите **«Всё равно открыть»**.

Необязательно: сверьте скачанный файл с `.sha256` из того же релиза:

```shell
shasum -a 256 -c VoiceInk-<версия>-arm64.dmg.sha256
```

Требования: Mac на Apple Silicon, macOS 15.0 или новее.

> [!NOTE]
> У этой сборки тот же идентификатор приложения, что у официального VoiceInk, поэтому настройки и данные у них общие. Не ставьте оба: сначала удалите официальное приложение.

## Обновления

Приложение не обновляется само. Кнопка **Check for Updates** (в настройках и в меню-баре) открывает страницу [Releases](https://github.com/ergSey/VoiceInk-Free/releases) этого репозитория. Чтобы узнавать о новых версиях, нажмите вверху этой страницы **Watch → Custom → Releases**.

## Изменения относительно оригинала

Исходный код — оригинальный. Изменения вносятся только при сборке скриптом [`scripts/free/patch.sh`](scripts/free/patch.sh):

- **Автопроверка обновлений выключена.** **Check for Updates** открывает страницу Releases этого репозитория. Фид обновлений Sparkle указывает на пустой [`appcast-free.xml`](appcast-free.xml), поэтому приложение никогда не предложит поставить официальную платную сборку.
- **Анонсы выключены по умолчанию.** Включить: Settings → General → Show Announcements.
- **Лицензия не нужна.** Приложение собрано с флагом `LOCAL_BUILD`: это собственный флаг оригинала для сборки из исходников.
- **Нет синхронизации словаря через iCloud** (её тоже выключает `LOCAL_BUILD`).
- **Только Apple Silicon (arm64).**
- **Ad-hoc подпись, без нотаризации.** Gatekeeper один раз потребует `xattr -cr` или **«Всё равно открыть»**, см. [Установку](#установка).
